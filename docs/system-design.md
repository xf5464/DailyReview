# DailyReview 系统设计文档

## 1. 系统目标

DailyReview 是一个全球宏观与市场指标仪表盘，同一套页面同时运行于：

- GitHub Pages 网页版：公开只读发布，数据由 GitHub Actions 定时构建。
- Electron 桌面版：本机窗口加载构建后的静态站点，分组与显示设置保存在独立的桌面用户目录。

两个版本共用 `site/` 前端和 `scripts/` 数据层。GitHub Pages 访问者的配置仍只属于各自浏览器；同一台电脑上的 Electron 桌面版和 `npm run preview` 本地网页版通过本机配置文件共享设置。

## 2. 目录与组件

```text
DailyReview/
├─ site/                       # HTML、CSS、前端交互与分享图
├─ scripts/
│  ├─ macro-outlook.js         # 数据源、解析、区间处理和容错
│  ├─ build.js                 # 生成 dist/ 和 data/outlook.json
│  └─ serve.js                 # 本地网页预览服务器
├─ desktop/main.js             # Electron 主进程与本机静态服务器
├─ test/macro-outlook.test.js  # 数据解析、区间与独立失败测试
├─ .github/workflows/
│  └─ deploy-pages.yml         # GitHub Pages 构建与部署
└─ dist/                       # 构建产物，不提交 Git
```

## 3. 数据构建

`npm run build` 执行以下流程：

1. 清空并重建 `dist/`。
2. 复制 `site/` 静态资源，并按 JS/CSS 内容哈希给资源 URL 加版本号，避免 GitHub Pages 的十分钟缓存继续运行旧前端。
3. 并行请求各指标最近三十年或数据源允许的最长可用历史。
4. 单个数据源失败时保留对应错误，不阻断其他指标。
5. 至少一个指标可用才写出 `dist/data/outlook.json`。

前端不在访问时直接请求第三方金融接口，只读取同版本构建产物，避免跨域、限流和不同用户看到不一致的数据。

页面时间区间包含 1 天、1/2/4 周、1/3/6 个月以及 1/2/3/5/7/10/15/20/25/30 年；月度与季度序列按观察期数量截取，日度序列按实际日期截取。

### 3.1 指标清单

当前共 34 个指标：

- 利率：美联储有效联邦基金利率、美国 10 年期和 30 年期国债收益率。
- 通胀：美国 CPI 同比、PCE 同比。
- 资产：黄金、白银、铜、比特币、布伦特原油、WTI 原油、Henry Hub 天然气。
- 官方部门黄金需求：全球央行净购金量。
- 财政与外汇：美国联邦债务、日元兑美元、美元指数（DXY）。
- A 股：中证全指成交额、沪深北三市融资余额、同花顺公开公式版活跃市值、同花顺情绪指数、影视院线成分股股东人数。
- 美股：纳斯达克 100 市盈率、NDX、标普 500、VIX。
- 美国制造业：ISM 制造业 PMI、供应商交付、新订单和订单积压指数。
- 宏观压力与就业：美债 10 年-2 年利差、高收益债信用利差、初次申请失业金、美国失业率、美国金融状况指数。

`federalFundsRate` 使用 FRED `DFF` 日度有效联邦基金利率（EFFR），单位为百分比，默认加入“默认”和“美国”分组。该指标反映美国存款类机构隔夜无担保联邦基金交易的实际利率水平，不等同于目标区间上下限。

`unemploymentRate` 使用 FRED `UNRATE` 月度季节调整失业率，单位为百分比，默认加入“默认”“美国”和“主要”分组；旧配置加载时会自动补入该指标及预设成员关系。

`pce` 以 FRED `PCEPI` 月度指数计算同比历史；构建时同时读取 BEA 官方新闻 RSS 和最新 Personal Income and Outlays 发布页，用官方公布的最新同比值补齐 FRED 尚未同步的月份。`vix` 以 FRED `VIXCLS` 保留历史，并用 CBOE 官方每日更新的 `VIX_History.csv` 收盘价覆盖和补齐最新交易日。两个补点源不可用时均自动回退到 FRED，不影响其他图表构建。

### 3.2 美元指数与 ISM 制造业

- `broadDollar` 为兼容既有浏览器配置保留旧图表 ID，但底层已从美联储广义贸易加权美元指数改为 ICE 美元指数（DXY）。DXY 使用欧元、日元、英镑、加元、瑞典克朗和瑞士法郎六种货币的固定权重篮子，不含人民币；图表读取 FRED H.10 的六个双边汇率序列并按 ICE 固定权重公式重建，历史从欧元汇率序列开始的 1999 年起可用。
- `ismManufacturingPmi`、`ismSupplierDeliveries`、`ismNewOrders` 和 `ismBacklogOrders` 分别表示 ISM 制造业 PMI、供应商交付、新订单和订单积压扩散指数。DBnomics 镜像提供长期历史，ISM 官方月报的核验快照覆盖镜像尚未同步的最新月份。
- 四个 ISM 指标均为月度、保留 1 位小数，默认加入“默认”和“美国”分组；图表显示 50 分界线，区间摘要使用点数变化而不是百分比涨跌。PMI、新订单和订单积压高于 50 表示扩张或增加；供应商交付高于 50 表示交付变慢。
- DBnomics 当前可用历史从 2020/2021 年开始；构建时只接受 20–80 点范围内的扩散指数值，以剔除上游页面结构变化造成的误解析记录。制造业 PMI 另与 DBnomics 保存的 ISM 官方“最近 12 个月”原始报告表格合并，修复主序列镜像末尾的误解析值。
- FRED 曾提供 `NAPM`、`NAPMNOI`、`NAPMSDI` 等 ISM 序列，但从 2016 年 6 月起按数据提供方要求删除，因此当前 FRED API 不再提供口径匹配的连续序列。若需补入更早历史，必须另行确认 ISM 授权或可合法再分发的连续档案，不能用工业产出等不同口径指标直接替代。

### 3.3 全球央行净购金量

- 图表 ID：`centralBankGoldPurchases`。
- 名称：全球央行净购金量。
- 口径：全球央行和其他官方部门机构的黄金买入量减去卖出量，包含 IMF 等超国家机构，剔除互换与 Delta 对冲影响；正值代表净买入，负值代表净卖出。
- 数据源：世界黄金协会 Gold Demand Trends，构建时从报告索引识别最新全球季度报告，再读取其中的“Quarterly central bank net purchases, tonnes”图表。
- 单位与显示：原始值保留吨数精度，卡片、坐标轴、提示和详情统一四舍五入为整数吨，不显示小数点。
- 更新频率：季度；报告历史数据可能随新信息修订。
- 历史范围：源图表提供 2014 年以来的季度序列；选择更长区间时显示数据源可提供的全部历史。

### 3.4 白银、铜与天然气价格

- `silver`：IMF Primary Commodity Price System（PCPS）的全球白银基准价，月度平均，单位为美元/盎司。
- `copper`：FRED 转发的 IMF 全球铜基准价（`PCOPPUSDM`），月度平均，单位为美元/吨。
- `naturalGas`：FRED 转发的美国能源信息署 Henry Hub 天然气现货价（`DHHNGSP`），日度，单位为美元/MMBtu。
- 三张图默认可见，并同时加入“默认”和“资源”内置分组；旧配置加载时会自动迁移新增指标。

### 3.5 原油临时补点

布伦特和 WTI 的历史主序列仍分别采用 EIA/FRED 日度现货价。若现货序列落后，构建时读取新浪财经 Brent（`OIL`）和 WTI（`CL`）近月期货日线，在最后一个现货观察日锚定价格，并以期货累计涨跌幅推算之后最多 14 个自然日的临时值：

```text
临时现货值 = 最后现货值 × 当日期货值 / 锚定日期货值
```

临时值在 JSON 中标记 `provisional: true`，前端使用虚线、端点和“临时补点”徽标显示，悬停说明其为期货涨跌幅推算值。后续构建一旦获得同日期的 EIA 现货观察值，主序列自然覆盖该日期，临时值不再生成。补点源失败不会影响现货主序列加载。

### 3.6 A 股融资余额

- 图表 ID：`aShareMarginBalance`。
- 名称：A股融资余额（三市）。
- 口径：沪、深、北三市尚未偿还的融资买入金额合计。
- 字段：东方财富公开数据中心 `RPTA_WEB_MARGIN_DAILYTRADE.FIN_BALANCE`，按页合并并按日期去重。
- 单位：该数据集的 `FIN_BALANCE` 已按亿元提供，构建时直接保留。
- 更新频率：交易日更新。
- 历史范围：该公开数据集自 2012 年 9 月起有记录；选择更长区间时显示数据源可提供的全部历史。
- 权威性说明：东方财富页面声明数据以交易所发布为准；指标用于观察杠杆资金存量，不代表确定的涨跌信号。

### 3.7 活跃度与流动性口径

指南针 `0AMV` 属于其自有活筹指标，未发现稳定公开 API 和完整统一算法，因此本项目不将第三方近似公式标记为原版 `0AMV`。项目新增的 `aShareActiveMarketValueThs` 使用同花顺指标平台上的公开用户公式：

```text
OAMV = 上证指数成交额 + 深证综指成交额
活跃市值 = SMA(OAMV, 10, 1) / 100,000,000
SMA 当日值 = (OAMV 当日亿元值 + 9 × SMA 前值) / 10
```

成交额从搜狐证券指数日线行情取得，正式区间前额外读取 180 天作为 SMA 预热期。该图名称固定为“A股活跃市值（同花顺公式版）”，说明中明确它来自用户上传公式、并非同花顺官方统一指数或指南针原版 `0AMV`。其他公开、可复现的活跃度观察口径包括：

- A 股成交额：衡量实际交易规模，项目已提供。
- 市值换手率：交易所定义为成交金额除以市价总值。
- Amihud 非流动性指标：绝对收益率除以成交金额，数值越高代表同等成交额引发的价格冲击越大。

若未来加入代理指标，名称和说明必须明确标注计算公式及“非指南针 0AMV”。

### 3.8 同花顺情绪指数

`aShareSentimentThs` 使用同花顺官方情绪指数 `883404` 的日度收盘点位。同花顺公开日线文件当前从 2022-08-10 开始；构建时先读取最近数据文件，再按其年份目录补齐所需历史分段，单个年份文件暂时不可用时回退到最近数据文件。FRED 不提供该中国市场专有指数，因此使用同花顺官方行情页及其同源公开日线数据。该图默认加入“默认”和“A股”分组，旧配置加载时会自动补入。

### 3.9 影视院线成分股股东人数

`filmCinemaShareholders` 以同花顺行业代码 `881274` 的官方成分股页面为股票范围，构建时动态读取当前全部成分股；每只股票优先读取同花顺移动 F10 的精确股东户数历史。总表详情可通过下拉框选择季度，也可用左右按钮逐季翻页，整张表统一显示所选季度户数及相对上一季度的人数变化，并显示同花顺行业页当前流通市值；股东人数、季度变化和流通市值三列均可点击表头排序。总表还可打开全部股票的最近四季度条状图界面，默认按截止季度股东人数从高到低排列，并可切换升降序及选择每行显示 1–5 张图。单股详情只保留 3 月 31 日、6 月 30 日、9 月 30 日和 12 月 31 日的股东人数季末记录，在曲线上显示全部季度点并支持选择时间跨度，但不提供逐季翻页；左轴为股东人数，右轴为同花顺真实周线收盘价连续曲线，不再将股价压缩成季度采样点。由于同花顺公开页当前仅给出约 5 年股东人数历史，更早区间用东方财富公开数据补齐，同日期仍以同花顺值为准；FRED 不提供中国个股流通市值或股价，市值和价格因此使用同花顺公开行情，价格请求失败时只省略右轴，不影响股东人数主图。详情和条状图界面均支持点击弹窗外空白背景关闭。

FRED 不提供中国上市公司级别的股东人数或同花顺行业成分数据，因此该指标不能使用 FRED。历史补充和单股回退均使用东方财富公开数据中心的 `RPT_HOLDERNUM_DET`；该接口无需密钥，并能返回精确户数及较长历史。回退按单股执行，不会因一只股票失败而丢失整张表；两处都失败时仍保留该成分股并标记暂无数据。AkShare、efinance 等免费库使用的也是东方财富公开接口封装，因此项目直接调用上游接口，避免增加运行依赖。巨潮资讯与交易所公告可用于人工核验，但没有适合本批量图表的稳定结构化时间序列接口。该图默认加入“默认”和“A股”分组。

## 4. 前端设计

前端使用原生 HTML、CSS、JavaScript 和 SVG，无运行时框架依赖。`site/app.js` 负责：

- 读取 `data/outlook.json` 并按时间范围过滤。
- 图表视图与表格视图。
- 单图详情、区间高低点、双指标双轴对比。
- 影视院线最新股东人数表格，以及点击单股后可按时间跨度查看的季度历史弹窗。
- 图表拖拽排序、显示/隐藏、分组成员管理，以及分组本身的拖拽、置顶和上下排序。“美国制造”为内置分组，旧版同名自定义分组会迁移并保留成员与顺序。
- 全局曲线宽度与季度详情点大小设置。

运行时能力按环境区分：Electron 桌面版和 `127.0.0.1` 本地预览显示“显示设置、管理分组、管理图表”；GitHub Pages 等远程网页端隐藏这三个本机管理入口，只保留查看、刷新、表格和对比功能。

卡片右上角的数值取当前筛选结果中日期最新的一条，使用指标原始单位精确显示，不使用“万、亿”等二次压缩记数，并在数值下方直接显示该观察日期。顶部“更新时间”是整批静态数据的构建时间，两者含义不同；遇到周末、节假日或数据源发布滞后时，观察日期可能早于构建时间。

卡片小图和详情标题旁均提供相同的问号说明，仅在鼠标悬停或键盘主动聚焦时显示。打开详情弹窗时焦点放在关闭按钮，说明默认关闭。详情范围达到约 3 年时，X 轴改用抽样年份的竖排标签；季度频率图表在详情中为每个季度绘制固定数据点，并保留悬停日期和值提示。

双指标对比图提供鼠标悬停提示：根据光标时间分别寻找左右序列最近的观察值，显示两个指标各自的日期、原始单位数值、垂直辅助线和对应颜色的数据点；油价临时补点会在提示中继续标注。

### 4.1 本地配置

- 总体配置键：`daily-review.overall-situation-config.v2`。
- 线宽配置键：`daily-review.chart-line-width.v1`。
- 季度点大小配置键：`daily-review.quarter-point-size.v1`。
- 线宽范围：1–6 px，步进 0.5 px，迁移后的默认值为 1 px。
- 季度点大小范围：2–10 px，步进 0.5 px，默认值为 4.5 px；只影响季度频率图表详情中的固定端点。

总体配置包含每行图表数、可见指标、分组、成员关系、各组独立顺序和当前分组。`DEFAULT_CONFIG` 维护“主要、美国制造、默认、美国、资源、A股”六个内置分组；A股内置分组默认包含成交额、融资余额、同花顺公式版活跃市值和同花顺情绪指数，“主要”内置分组包含 30 年期美债收益率、CPI、美国失业率、黄金、标普 500、布伦特原油、有效联邦基金利率、铜和全球央行净购金量。所有图表永久属于“默认”组；新增指标和新增内置分组会按预设成员与顺序自动迁移到旧配置，并按分组名称去重，避免同名分组重复。总体配置与显示配置均支持 JSON 导入、导出和恢复默认。

配置始终写入当前运行环境的 `localStorage`。在桌面版和 `127.0.0.1` 本地预览中，页面还会通过同源 `/api/local-config` 接口同步到 `~/.daily-review/settings.json`；任一端修改分组、顺序、可见性、线宽或季度点大小后，另一端下次打开即可读取同一份配置。该文件也避免 Electron 随机本机端口变化导致配置看似丢失。内置分组顺序带独立版本号，默认顺序升级时会迁移旧内置分组，同时保留迁移后由用户主动调整的顺序。

GitHub Pages 是远程纯静态站点，浏览器安全模型不允许它直接读取电脑上的该文件，因此线上网页仍使用其自身的 `localStorage`。如需跨设备或让线上网页使用同一配置，继续使用页面的 JSON 导入/导出功能。

## 5. Electron 桌面版

`desktop/main.js` 在 `127.0.0.1` 的随机端口启动本机 HTTP 服务，再由沙箱化 `BrowserWindow` 加载。除 `dist/` 静态文件外，只额外提供受大小限制的同源本机配置读写接口。使用 HTTP 而不是 `file://`，确保 JSON `fetch` 行为与网页版一致。

安全设置：

- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`
- 单实例运行
- 外部链接只允许 HTTP/HTTPS，并交给系统浏览器
- 路径解析阻止访问 `dist/` 之外的文件

启动与打包：

```powershell
npm run desktop       # 获取最新数据后启动
npm run desktop:open  # 使用已有 dist/ 直接启动
npm run desktop:dist  # 生成 Windows NSIS 安装程序
```

`npm test` 覆盖 CSV/JSON 解析、同比换算、时间范围、选择性请求和单源失败隔离。新增或修改指标时必须同步：

1. 更新 `scripts/macro-outlook.js` 元数据、URL、解析器和加载器。
2. 更新 `site/app.js` 标题、类别、说明、颜色和默认配置。
3. 增加解析及完整查询测试。
4. 更新本设计文档中的指标与口径。
5. 运行 `npm test` 和 `npm run build`，确认所有可用数据源成功生成。
