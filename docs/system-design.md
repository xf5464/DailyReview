# DailyReview 系统设计文档

## 1. 系统目标

DailyReview 是一个全球宏观与市场指标仪表盘，同一套页面同时运行于：

- GitHub Pages 网页版：公开只读发布，数据由 GitHub Actions 定时构建。
- Electron 桌面版：本机窗口加载构建后的静态站点，分组与显示设置保存在独立的桌面用户目录。

两个版本共用 `site/` 前端和 `scripts/` 数据层。GitHub Pages 访问者的配置仍只属于各自浏览器；同一台电脑上的 Electron 桌面版和 `npm run preview` 本地网页版通过本机配置文件共享设置。

## 2. 目录与组件

```text
DailyReview/
├─ site/                       # HTML、CSS、前端交互、PWA 外壳与分享图
├─ scripts/
│  ├─ macro-outlook.js         # 数据源、解析、区间处理和容错
│  ├─ build.js                 # 生成 dist/、轻量数据清单和单指标文件
│  └─ serve.js                 # 本地网页预览服务器
├─ desktop/main.js             # Electron 主进程与本机静态服务器
├─ test/macro-outlook.test.js  # 数据解析、区间与独立失败测试
├─ .github/workflows/
│  └─ deploy-pages.yml         # GitHub Pages 构建与部署
└─ dist/                       # 构建产物，不提交 Git
```

## 3. 数据构建

`npm run build` 执行以下流程：

1. 清空并重建 `dist/`。
2. 复制 `site/` 静态资源，并按 JS/CSS 内容哈希给资源 URL 加版本号，避免 GitHub Pages 的十分钟缓存继续运行旧前端。
3. 并行请求各指标最近三十年或数据源允许的最长可用历史。
4. 单个数据源失败时保留对应错误，不阻断其他指标。
5. 至少一个指标可用才写出轻量清单 `dist/data/outlook.json`，并将 38 个完整指标分别写入 `dist/data/charts/<id>.json`。
6. 同时按“指标 + 年份”生成内容寻址的离线分块 `dist/data/offline/<id>/items-<year>.<hash>.json`；图表额外字段单独生成 `extras.<hash>.json`，`offline-manifest.json` 记录每个分块的 SHA-256 截断哈希、字节数和整图签名。

前端不在访问时直接请求第三方金融接口，只读取同版本构建产物，避免跨域、限流和不同用户看到不一致的数据。

页头“全球市场”是独立的盘中行情入口，不属于长期宏观指标构建。打开后由现有 `dailyreview-reader` Cloudflare Worker 聚合国际指数、大宗商品、美债收益率和外汇的免费盘中行情，弹窗立即请求一次，保持打开时每 60 秒刷新，关闭或切到后台后停止请求。卡片显示当前价、相对前收涨跌幅和当日迷你走势；涨跌配色遵循 A 股习惯，红色表示上涨、绿色表示下跌。顶部交易时段全部换算为东八区，美股、加拿大和欧洲交易时段通过 IANA 时区自动处理夏令时。

FRED 提供的股票、商品和利率序列以日度或更低频率为主，不提供此处所需的多市场盘中报价，因此实时总览使用 Yahoo Finance 的免费公开图表接口，不使用需要付费的 MarketWatch。Worker 对完整聚合结果缓存 60 秒，对最近一次成功的单项行情保留 24 小时降级缓存；某个代码超时或限流时仅回退该卡片，其余市场继续显示。浏览器也保留最近一次成功结果，断网或 Worker 临时不可用时可显示上次缓存。行情源在午休或缺少某个 5 分钟收盘价时会返回空值，Worker 必须丢弃该点，禁止把空值转换成 0 后造成曲线瞬间下探；变更这一规则时同步更新缓存版本，避免复用旧的错误曲线。界面明确提示免费行情仅供参考，海外市场可能存在约 15 分钟延迟，不将其表述为交易所直连实时行情。行情卡片可配置每行显示 2、3 或 4 个，默认 4 个，选择保存在当前浏览器并在手机端同步使用。

页面时间区间包含 1 天、1/2/4 周、1/3/6 个月以及 1/2/3/5/7/10/15/20/25/30 年；月度与季度序列按观察期数量截取，日度序列按实际日期截取。

### 3.1 指标清单

当前共 39 个指标：

- 经济日历：未来 12 个月美国 CPI、PCE、非农就业和 FOMC 官方发布日期。
- 利率：美联储有效联邦基金利率、美国 10 年期和 30 年期国债收益率。
- 通胀：美国 CPI 同比、PCE 同比。
- 资产：黄金、白银、铜、比特币、布伦特原油、WTI 原油、Henry Hub 天然气。
- 官方部门黄金需求：全球央行净购金量。
- 财政与外汇：美国联邦债务、日元兑美元、美元指数（DXY）。
- A 股：中证全指成交额、沪深北三市融资余额、同花顺公开公式版活跃市值、A 股行业资金集中度、同花顺情绪指数、A 股每月新增开户数、影视院线成分股股东人数、国家队宽基 ETF 持仓市值。
- 美股：纳斯达克 100 市盈率、NDX、标普 500、VIX。
- 美国制造业：ISM 制造业 PMI、供应商交付、新订单和订单积压指数。
- 宏观压力与就业：美债 10 年-2 年利差、高收益债信用利差、初次申请失业金、美国失业率、美国金融状况指数。

`federalFundsRate` 使用 FRED `DFF` 日度有效联邦基金利率（EFFR），单位为百分比，默认加入“默认”和“美国”分组。该指标反映美国存款类机构隔夜无担保联邦基金交易的实际利率水平，不等同于目标区间上下限。

`unemploymentRate` 使用 FRED `UNRATE` 月度季节调整失业率，单位为百分比，默认加入“默认”“美国”和“主要”分组；旧配置加载时会自动补入该指标及预设成员关系。

`pce` 以 FRED `PCEPI` 月度指数计算同比历史；构建时同时读取 BEA 官方新闻 RSS 和最新 Personal Income and Outlays 发布页，用官方公布的最新同比值补齐 FRED 尚未同步的月份。`vix` 以 FRED `VIXCLS` 保留历史，并用 CBOE 官方每日更新的 `VIX_History.csv` 收盘价覆盖和补齐最新交易日。两个补点源不可用时均自动回退到 FRED，不影响其他图表构建。

`aShareTurnover` 表示中证全指（000985）日成交额，单位为亿元。FRED 仅提供中国股票市场年度换手率、成交额占 GDP 比例和月度股价指数，没有日度全市场成交额这一口径，因此不能替代本指标。构建时优先读取中证指数官网，失败时读取东方财富同指数日线成交额；两处中国站点均因 GitHub 云端网络暂时不可达时，回退到仓库内最后一次成功快照并在来源名称中显示快照截止日期，避免短暂网络故障发布空图。工作日北京时间 16:20 的独立任务负责更新该持久化快照，更新任务失败不会覆盖已有快照。

`aShareIndustryConcentration` 使用东方财富行业板块日成交额计算行业资金集中度。主序列 C5 为成交额排名前五的行业成交额之和除以全部行业成交额；详情同时显示各行业成交额占比平方和乘以 10000 的 HHI、当日有效行业数，以及成交额前五行业的成交额和占比。点击前五行业中的任意一行会打开该行业的双轴历史图：左轴为日成交额（亿元），右轴为东方财富行业指数收盘点位；时间跨度默认一年，并允许切换其他范围。行业历史使用紧凑数组保存到同一指标的离线 extras 中，因此离线下载后也能打开，不额外依赖浏览器实时请求。计算使用已核验的 86 个行业固定样本，官网目录可用时会同步这些行业的最新名称，目录异常时使用同一份快照；固定样本既避免分类增删导致历史口径跳变，也减少批量请求被源站拒绝。构建只在至少 95% 行业板块历史成功且单日覆盖率达到 95% 时生成数据，避免部分板块请求失败造成集中度虚高。FRED 已检查到的中国股市相关序列只有年度市场换手率、成交额占 GDP 比例和月度股价等总量数据，没有日度行业成交额或行业集中度，因此不符合本指标口径；这里使用东方财富行业板块作为计算源。

#### 3.1.1 未来 12 个月美国经济日历

`usEconomicCalendar` 是独立的 `economicCalendar` 图表类型，覆盖构建日（含）到之后 12 个月的已公布事件。总览卡片使用 CPI、PCE、非农就业和 FOMC 四条轨道显示日期点；详情按日期列出事件，并允许分别勾选四类项目。所有公布时间在构建阶段从美国东部时间换算为东八区，自动处理美国夏令时；详情顶部统一说明时区，各事件时间显示在左侧星期右边，不重复附加时区文字。FOMC 决议若换算后落在次日，日期、排序和时间轴位置一并顺延，并在详情保留美国当地会议起止日。勾选状态写入总体配置，立即同时作用于总览和详情。

选源时先检查 FRED Release Calendar；该页面只提供较短的近期发布窗口，不能稳定覆盖未来 12 个月，因此本指标改用各发布机构的一手日程：BLS 的 CPI 与 Employment Situation 日程、BEA 的 Personal Income and Outlays 日程，以及 Federal Reserve 的 FOMC 会议日历。页面只展示机构已经正式公布的日期，不根据历史规律补造尚未公布的月份；因此远期月份可能暂时为空。FOMC 以两日会议的第二日（议息决定日）定位，同时保留起始日，并标记带 `*` 的经济预测会议。BLS、BEA 和 Federal Reserve 按类别并行、独立容错；某一官网当次不可用或结构异常时，只对该类别回退到 `2026-09-09` 核验的一手日程快照，并在详情中明确提示，避免整张日历为空或其他类别被连带丢失。

页头“预测”入口根据四个可配置的“或者”条件展示当前状态：NDX 相对历史最高点的回撤达到指定百分比、VIX 达到指定点位、美国失业率达到指定百分比，或萨姆规则达到指定升幅。NDX 使用 FRED `NASDAQ100` 日度指数序列；VIX 沿用 FRED `VIXCLS` 主序列及 CBOE 最新收盘价补点；美国失业率复用 FRED `UNRATE` 月度季节调整序列；萨姆规则直接使用 FRED `SAHMCURRENT` 月度序列。四项均存在 FRED 口径匹配序列，因此不另接 ETF 或第三方行情。默认阈值分别为 30%、30 点、6% 和 0.5 个百分点，原有失业率绝对值条件继续保留。每个指标名称后的问号可点击显示指标含义和数值解读。阈值默认锁定，点击各条件的“编辑”后才可修改；弹窗初始焦点放在关闭按钮。“条件数据”界面默认勾选四项，并从主界面复制当前阈值作为本次查询的初始值；用户可在该界面临时编辑各条件阈值，但不写入配置且不改变主界面阈值。执行后仅按日期倒序展示所有已选条件同时达到本次查询阈值的日期与数值；不同发布频率的序列按时间向前填充已发布值，不引入未来数据。结果每批显示 200 条，可继续加载更多，避免长历史序列一次性渲染造成移动端卡顿。

每项预测条件均提供独立回测界面和时间范围选择。NDX 回测在每个交易日仅使用截至当日的累计历史最高点计算回撤，避免引入未来数据；其左轴与蓝色曲线显示回撤比例，右轴与紫色曲线显示原始 NDX 指数点位。VIX 回测直接比较当日收盘点位与阈值，其左轴与蓝色曲线显示 VIX 点位，右轴与紫色曲线显示同期 NDX 指数点位。失业率和萨姆规则回测分别按月比较 FRED `UNRATE`、`SAHMCURRENT` 与各自阈值，左轴与蓝色曲线显示对应条件值，右轴与紫色曲线显示同期 NDX 指数点位。达到条件的数据点在条件曲线上以红色高亮点标记，并汇总命中数量及连续命中区段数量。鼠标悬停或触摸曲线和红色命中点时显示日期、对应数值及是否达到条件，四种回测均在同一提示中显示条件值与 NDX 点位；NDX 回撤提示还显示截至当前点的历史最高点日期与具体点位。图中同时标明当前单位和阈值；所选时间跨度超过 3 年时，X 轴改为竖排年份，并从首个可见年份开始隔一年标注一次。

### 3.2 美元指数与 ISM 制造业

- `broadDollar` 为兼容既有浏览器配置保留旧图表 ID，但底层已从美联储广义贸易加权美元指数改为 ICE 美元指数（DXY）。DXY 使用欧元、日元、英镑、加元、瑞典克朗和瑞士法郎六种货币的固定权重篮子，不含人民币；图表读取 FRED H.10 的六个双边汇率序列并按 ICE 固定权重公式重建，历史从欧元汇率序列开始的 1999 年起可用。
- `ismManufacturingPmi`、`ismSupplierDeliveries`、`ismNewOrders` 和 `ismBacklogOrders` 分别表示 ISM 制造业 PMI、供应商交付、新订单和订单积压扩散指数。DBnomics 镜像提供长期历史，ISM 官方月报的核验快照覆盖镜像尚未同步的最新月份。
- 四个 ISM 指标均为月度、保留 1 位小数，默认加入“默认”和“美国”分组；图表显示 50 分界线，区间摘要使用点数变化而不是百分比涨跌。PMI、新订单和订单积压高于 50 表示扩张或增加；供应商交付高于 50 表示交付变慢。
- DBnomics 当前可用历史从 2020/2021 年开始；构建时只接受 20–80 点范围内的扩散指数值，以剔除上游页面结构变化造成的误解析记录。制造业 PMI 另与 DBnomics 保存的 ISM 官方“最近 12 个月”原始报告表格合并，修复主序列镜像末尾的误解析值。
- FRED 曾提供 `NAPM`、`NAPMNOI`、`NAPMSDI` 等 ISM 序列，但从 2016 年 6 月起按数据提供方要求删除，因此当前 FRED API 不再提供口径匹配的连续序列。若需补入更早历史，必须另行确认 ISM 授权或可合法再分发的连续档案，不能用工业产出等不同口径指标直接替代。

### 3.3 全球央行净购金量

- 图表 ID：`centralBankGoldPurchases`。
- 名称：全球央行净购金量。
- 口径：全球央行和其他官方部门机构的黄金买入量减去卖出量，包含 IMF 等超国家机构，剔除互换与 Delta 对冲影响；正值代表净买入，负值代表净卖出。
- 数据源：世界黄金协会 Gold Demand Trends，构建时从报告索引识别最新全球季度报告，再读取其中的“Quarterly central bank net purchases, tonnes”图表。
- 单位与显示：原始值保留吨数精度，卡片、坐标轴、提示和详情统一四舍五入为整数吨，不显示小数点。
- 更新频率：季度；报告历史数据可能随新信息修订。
- 历史范围：源图表提供 2014 年以来的季度序列；选择更长区间时显示数据源可提供的全部历史。

### 3.4 白银、铜与天然气价格

- `silver`：IMF Primary Commodity Price System（PCPS）的全球白银基准价，月度平均，单位为美元/盎司。
- `copper`：FRED 转发的 IMF 全球铜基准价（`PCOPPUSDM`），月度平均，单位为美元/吨。
- `naturalGas`：FRED 转发的美国能源信息署 Henry Hub 天然气现货价（`DHHNGSP`），日度，单位为美元/MMBtu。
- 三张图默认可见，并同时加入“默认”和“资源”内置分组；旧配置加载时会自动迁移新增指标。

### 3.5 原油临时补点

布伦特和 WTI 的历史主序列仍分别采用 EIA/FRED 日度现货价。若现货序列落后，构建时读取新浪财经 Brent（`OIL`）和 WTI（`CL`）近月期货日线，在最后一个现货观察日锚定价格，并以期货累计涨跌幅推算之后最多 14 个自然日的临时值：

```text
临时现货值 = 最后现货值 × 当日期货值 / 锚定日期货值
```

临时值在 JSON 中标记 `provisional: true`，前端使用虚线、端点和“临时补点”徽标显示，悬停说明其为期货涨跌幅推算值。后续构建一旦获得同日期的 EIA 现货观察值，主序列自然覆盖该日期，临时值不再生成。补点源失败不会影响现货主序列加载。

### 3.6 A 股融资余额

- 图表 ID：`aShareMarginBalance`。
- 名称：A股融资余额（三市）。
- 口径：沪、深、北三市尚未偿还的融资买入金额合计。
- 字段：东方财富公开数据中心 `RPTA_WEB_MARGIN_DAILYTRADE.FIN_BALANCE`，按页合并并按日期去重。
- 单位：该数据集的 `FIN_BALANCE` 已按亿元提供，构建时直接保留。
- 更新频率：交易日更新。
- 历史范围：该公开数据集自 2012 年 9 月起有记录；选择更长区间时显示数据源可提供的全部历史。
- 权威性说明：东方财富页面声明数据以交易所发布为准；指标用于观察杠杆资金存量，不代表确定的涨跌信号。

### 3.7 活跃度与流动性口径

指南针 `0AMV` 属于其自有活筹指标，未发现稳定公开 API 和完整统一算法，因此本项目不将第三方近似公式标记为原版 `0AMV`。项目新增的 `aShareActiveMarketValueThs` 使用同花顺指标平台上的公开用户公式：

```text
OAMV = 上证指数成交额 + 深证综指成交额
活跃市值 = SMA(OAMV, 10, 1) / 100,000,000
SMA 当日值 = (OAMV 当日亿元值 + 9 × SMA 前值) / 10
```

成交额从搜狐证券指数日线行情取得，正式区间前额外读取 180 天作为 SMA 预热期。该图名称固定为“A股活跃市值（同花顺公式版）”，说明中明确它来自用户上传公式、并非同花顺官方统一指数或指南针原版 `0AMV`。其他公开、可复现的活跃度观察口径包括：

- 市值换手率：交易所定义为成交金额除以市价总值。

### A股 PE（最新交易日估值）

历史图悬停提示同时显示该点日期、PE和过去所选年数的百分位。计算窗口截止于悬停点，使用完整历史中的此前样本，不包含未来数据，也不受当前曲线显示范围裁剪；历史不足时注明实际覆盖。切换百分位年数后重新计算，重复悬停同一日期复用结果。

## 4. 前端设计

前端使用原生 HTML、CSS、JavaScript 和 SVG，无运行时框架依赖。`site/app.js` 负责：

- 首先读取轻量 `data/outlook.json` 清单，仅并行加载当前分组中可见指标对应的 `data/charts/<id>.json`，再按时间范围过滤。切换分组时只补载尚未读取的指标；已加载文件按构建时间版本复用浏览器缓存。
- 图表视图与表格视图。
- 单图详情、区间高低点、双指标双轴对比。
- 未来 12 个月美国经济日历的四轨日期图、按日期详情列表和可持久化类别勾选。
- NDX 回撤、VIX 点位、美国失业率与萨姆规则预测条件，以及带时间范围和醒目标记的历史回测。
- 影视院线最新股东人数表格，以及点击单股后可按时间跨度查看的季度历史弹窗。
- 图表拖拽排序、显示/隐藏、分组成员管理，以及分组本身的拖拽、置顶和上下排序。“美国制造”为内置分组，旧版同名自定义分组会迁移并保留成员与顺序。
- 全局曲线宽度与季度详情点大小设置。

运行时能力按环境区分：Electron 桌面版和 `127.0.0.1` 本地预览显示“显示设置、管理分组、管理图表”；GitHub Pages 等远程网页端隐藏这三个本机管理入口，只保留查看、刷新、表格和对比功能。

普通指标卡片右上角的数值取当前筛选结果中日期最新的一条，使用指标原始单位精确显示，不使用“万、亿”等二次压缩记数，并在数值下方直接显示该观察日期。经济日历卡片属于例外：右上角显示下一项已勾选事件距今天数及事件日期，不显示历史数值。顶部“更新时间”是整批静态数据的构建时间，两者含义不同；遇到周末、节假日或数据源发布滞后时，观察日期可能早于构建时间。

卡片小图和详情标题旁均提供相同的问号说明，仅在鼠标悬停或键盘主动聚焦时显示。打开详情弹窗时焦点放在关闭按钮，说明默认关闭。详情范围达到约 3 年时，X 轴改用抽样年份的竖排标签；季度频率图表在详情中为每个季度绘制固定数据点，并保留悬停日期和值提示。

双指标对比图提供鼠标悬停提示：根据光标时间分别寻找左右序列最近的观察值，显示两个指标各自的日期、原始单位数值、垂直辅助线和对应颜色的数据点；油价临时补点会在提示中继续标注。

- 总体配置键：`daily-review.overall-situation-config.v2`。

配置始终写入当前运行环境的 `localStorage`。在桌面版和 `127.0.0.1` 本地预览中，页面还会通过同源 `/api/local-config` 接口同步到 `~/.daily-review/settings.json`；任一端修改分组、顺序、可见性、经济日历勾选、预测阈值、线宽或季度点大小后，另一端下次打开即可读取同一份配置。该文件也避免 Electron 随机本机端口变化导致配置看似丢失。内置分组顺序带独立版本号；版本 4 会在手机等已有配置中一次性把经济日历补到“主要”分组首位，迁移完成后的用户调整仍会保留。

GitHub Pages 是远程纯静态站点，浏览器安全模型不允许它直接读取电脑上的该文件，因此线上网页仍使用其自身的 `localStorage`。如需跨设备或让线上网页使用同一配置，继续使用页面的 JSON 导入/导出功能。

### 4.2 iOS PWA 与增量离线数据

页面提供 Web App Manifest、应用图标和 Service Worker，可从 iPhone Safari 的分享菜单添加到主屏幕，以独立窗口运行。应用外壳采用缓存优先、导航和数据清单采用联网优先并回退本地缓存；普通在线浏览仍只加载当前分组。

同花顺情绪指数优先读取官方 `883404/00/last.js` 行情；该入口返回 502、超时或无效内容时，构建必须自动改读 2022 年起的官方年度分段，并要求当前年份分段成功后才发布该指标，避免一次临时网关故障覆盖成空图表。

构建产物用应用外壳内容哈希生成 `app-version.json` 和独立的 Service Worker 缓存名；页面展示的 GitHub Actions 运行编号只作为可见发布编号，禁止覆盖内容哈希，因此纯数据部署不会被误判成应用升级。手机浏览器每次启动会以网络无缓存方式检查应用版本，发现新版时等待页面进入前台，使用不锁定页面的非模态更新框并完成两帧绘制，再安装新版 Service Worker。新版 Worker 激活时只更新缓存并接管请求，Worker 和页面代码都禁止主动导航或刷新当前页面；当前会话继续离线数据检查，新应用外壳在用户下次自然打开时生效，避免 iOS 导航挂起导致页面失去点击。安装失败则短暂提示并继续使用当前版本，下次启动重试。非手机浏览器仍注册并检查 Service Worker，但不显示移动端更新框。手机 Web App 在联网时还会读取离线清单，用每个指标的内容签名与本地离线状态比较；首次尚未下载，或确有指标新增、删除、数据修订时自动打开离线数据界面并开始下载，内容完全一致或检测失败时不弹窗。自动离线更新必须等待页面进入前台，以非模态界面显示并至少让浏览器完成两帧绘制，再开始缓存检查，使数据下载期间仍可操作页面；自动更新期间延后统计全部缓存容量，缓存缺失检查使用一次缓存目录索引，禁止逐分块串行查询造成启动假死。PC 端不会在启动时弹出离线数据界面，仍可通过“离线数据”按钮手动下载。脚本和样式采用网络优先、缓存回退策略。每次部署会把全部年度分块和总览数据压缩成带内容哈希文件名的 ZIP；首次全量下载或浏览器清空全部数据分块后，网页优先一次下载 ZIP，在本地解压、逐文件校验并写入 Cache Storage，再重组出前端原有的完整单指标 JSON。ZIP 下载、解压或校验失败时自动回退到原有逐文件下载，并继续保留上次成功缓存。已有完整缓存时仍按内容哈希增量更新，只有新增年份、最新年份新增记录或历史修订涉及的分块会重新下载。下载和校验全部成功后才写入新版本状态并清理旧内容寻址分块。个人配置仍保存在 `localStorage`，不会被离线数据更新覆盖。

### 沪市、深市 A 股换手率

FRED 的中国换手率 DDEM01CNA156NWDB 为年度且停留于2020年，无法满足日度历史及滚动三年百分位。直接采用上交所每日股票情况（主板A PRODUCT_CODE=01、科创板03）和深交所证券类别统计（主板A股、创业板A股），每日以两板块成交额合计除以总市值合计乘100%，排除B股；不得把两个板块换手率直接平均，亦不得称为自由流通换手率。日期必须与返回数据日期一致，休市缺值不补零。

总览表格百分位背景优先判定双周期极值（包括PE两项）：一年与三年均≥90%使用紫色背景，均≤10%使用黄色背景。其余情况只看三年：≥90%使用红色，从90%到100%逐渐加深；≤10%使用绿色，从10%到0%逐渐加深；中间值不着色。按显示精度判定，星号不影响判断；缺少一年值时仍可按有效三年值着色，缺少三年值不着色。竖线保持普通文本。

百分位颜色应用于总览表格完整指标行的全部单元格，包括名称、最新数值、百分位与其他列；数字本身不再使用独立背景块。PE合并行包含两个指标时，上半行对应全A，下半行对应科创50，按各自规则横向铺满整行，不改变倍字及百分位对齐布局。

#### 手动采集与生产校验（计算版本 2）

- 手动入口为 `npm run prepare:active-fund-universe` 和 `npm run update:active-fund-crowding`。基金目录只生成候选产品，不能据此声称历史全市场覆盖率；前后端收费代码与 A/C 类名称去重只作候选筛选，生产输入须以逐季度已核验的产品身份去重。
- 生产更新要求逐季度主动权益基金成员、产品 ID、当季净资产及类型历史的核验记录，以及同一东方财富二级分类版本下逐季度股票行业映射。仅给一个基金数量分母或当前存续基金名单不能发布历史百分位。
- 数据覆盖率取基金数量覆盖率、季度净资产覆盖率、持仓市值行业映射率三者最小值；三者均至少 90% 才接纳季度。映射率按持仓市值计算，不按股票条数计算；未映射股票市值保留在占比分母中。
- 所有年份统一使用季报前十大股票持仓；报告日期、季度、股票代码、名次、重复股票及持仓市值均校验。当前保守要求每份报告恰有十条有效重仓股；实际不足十只的报告先进入诊断，不自动推断披露完整。持仓市值为万元，基金季度净资产也为万元。
- 季度变化仅比较相邻季度；1/3/5/10 年百分位分别要求 5/13/21/41 个连续季度观察值。缺季、行业缺值或分类版本不同均不跨越计算，不补零。
- 原始响应按稳定 URL 保存并记录 SHA-256、来源 URL 和采集时间；成功响应可断点复用，`--refresh` 明确重新请求。本地核验记录保存成功基金及原始报告指纹；生产快照只保存季度行业汇总、计算版本、输入哈希、覆盖率分项及本地核验记录摘要指纹。普通构建只验证并复制紧凑快照，不发起采集或重算。
- 快照写入使用临时文件和原子替换；更新前归档旧版，禁止用更早报告期或缺失已有季度历史的新结果覆盖。最新请求季度不达标时整个发布失败，保留旧快照。

- 本次未生成生产快照：尚缺逐季度基金成员与净资产核验、清盘及转型基金处理、股票二级行业历史映射。试采集使用空行业映射，覆盖率明确为 0，不代表真实行业统计。输入格式和复现命令见 `docs/active-fund-crowding-update.md`。
