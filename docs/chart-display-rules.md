# 小图表显示规则

本文定义 DailyReview 总览页小图表的统一显示规则。新增指标时必须遵循本规则，避免在单个图表中写死特殊时间跨度或横轴格式。

## 1. 统一观察期配置

总览页小图使用两个统一配置值：

```js
const overviewMiniChartPeriods = {
  monthly: 12,
  quarterly: 12,
};
```

含义：

- **季度型小图**：如果图表 `frequency` 包含“季”，固定显示最近 **12 个季度**。
- **月度显示型小图**：其余普通时间序列小图，无论底层原始数据是日度、周度还是月度，都在总览卡片中显示最近 **12 个月**。例如黄金、布伦特原油、WTI、VIX、国债收益率虽然原始数据是日度，但总览小图仍按最近 12 个月展示。
- 所有普通总览折线小图必须读取上述配置值，不得在单独指标中再写 `12` 或针对某个图表 ID 做特殊判断。
- `stockTable`、`wideEtfTable` 等表格型卡片不套用普通折线小图的时间窗口规则。
- 详情图、对比图、回测图等不是“总览页小图”的视图，继续使用各自的时间选择器，不受这两个固定观察期配置约束。

构建时，`scripts/build.js` 会把这两个配置值注入前端运行时的 `OVERVIEW_MINI_CHART_PERIODS`。普通总览折线卡片先按图表类型判断：季度频率取最近 `quarterly` 个季度；其他时间序列按最新日期向前截取 `monthly` 个月。因此以后新增日度、周度、月度或季度普通折线图后，都应自动继承本规则，不需要增加图表 ID 特判。

## 2. 小图横轴日期格式

总览小图使用紧凑横轴标签，避免重复显示不必要的年份。

### 月度显示型小图

日度、周度、月度等非季度普通折线小图，横轴统一按月份表达。同一年内只显示月份：

```text
3月   8月   12月
```

跨年时，仅在需要区分年份的位置补充年份，例如：

```text
2025年9月   2月   2026年8月
```

底层仍保留原始日度、周度或月度数据点，只有总览小图的横轴文字采用月份格式；悬停提示仍显示该数据点的完整日期和值。

### 季度小图

季度统一使用 `Q1`、`Q2`、`Q3`、`Q4`。同一年内不重复年份；跨年时只在需要区分年份的位置显示年份，例如：

```text
2024年Q3   2025年Q4   2026年Q2
```

完整日期仍保留在悬停提示、详情页和区间摘要中，不因小图横轴压缩而丢失。

## 3. 新增图表规范

新增图表时：

1. 必须正确填写 `frequency`。季度图必须包含“季”；其他普通时间序列会自动归入 12 个月总览窗口。
2. 普通总览折线小图不要自行设置最近 N 期数据。
3. 不要针对具体图表 ID 写总览观察期或横轴格式特判。
4. 如果产品需求需要修改普通小图的默认长度，只修改 `scripts/build.js` 中 `overviewMiniChartPeriods.monthly` 或 `overviewMiniChartPeriods.quarterly`，并同步更新本文档。
5. 新增图表完成后必须至少检查四类代表：日度、周度、月度、季度，确认总览卡片分别落入 12 个月或 12 季度规则。
6. 如果某张图确实必须例外，应先明确记录业务原因，并优先设计成独立图表类型，而不是继续增加 ID 特判。

此规则用于保证已有图表和未来新增图表的总览显示行为一致。
