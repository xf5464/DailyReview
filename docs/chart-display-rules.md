# 小图表显示规则

本文定义 DailyReview 总览页小图表的统一显示规则。新增指标时必须遵循本规则，避免在单个图表中写死特殊时间跨度或横轴格式。

## 1. 统一观察期配置

总览页小图使用两个统一配置值：

```js
const overviewMiniChartPeriods = {
  monthly: 12,
  quarterly: 12,
};
```

含义：

- 月度序列的小图表固定显示最近 **12 个月**。
- 季度序列的小图表固定显示最近 **12 个季度**。
- 所有月度、季度小图必须读取上述配置值，不得在单独指标中再写 `12` 或针对某个图表 ID 做特殊判断。
- 日度、周度等其他频率的小图仍按总览页时间选择器的区间显示。
- 详情图、对比图、回测图等不是“总览页小图”的视图，继续使用各自的时间选择器，不受这两个固定观察期配置约束。

构建时，`scripts/build.js` 会把这两个配置值注入前端运行时的 `OVERVIEW_MINI_CHART_PERIODS`，总览卡片统一按指标的 `frequency` 判断并截取数据。因此以后新增一个 `frequency` 含“月”或“季”的普通折线图后，应自动继承此规则，不需要增加图表 ID 特判。

## 2. 小图横轴日期格式

月度和季度小图使用紧凑横轴标签，避免重复显示不必要的年份。

### 月度

同一年内只显示月份：

```text
3月   8月   12月
```

跨年时，仅在需要区分年份的位置补充年份，例如：

```text
2025年9月   2月   2026年8月
```

### 季度

季度统一使用 `Q1`、`Q2`、`Q3`、`Q4`。同一年内不重复年份；跨年时只在需要区分年份的位置显示年份，例如：

```text
2024年Q3   2025年Q4   2026年Q2
```

完整日期仍保留在悬停提示、详情页和区间摘要中，不因小图横轴压缩而丢失。

## 3. 新增图表规范

新增图表时：

1. 正确填写 `frequency`，月度使用包含“月”的频率描述，季度使用包含“季”的频率描述。
2. 普通总览折线小图不要自行设置最近 N 期数据。
3. 不要针对具体图表 ID 写月度或季度窗口特判。
4. 如果产品需求需要修改所有月度或季度小图的默认长度，只修改 `scripts/build.js` 中的 `overviewMiniChartPeriods` 配置值，并同步更新本文档。
5. 如果某张图确实必须例外，应先明确记录业务原因，并优先设计成独立图表类型，而不是继续增加 ID 特判。

此规则用于保证已有图表和未来新增图表的总览显示行为一致。
